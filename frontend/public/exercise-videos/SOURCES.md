# Fontes das demonstrações

Os clipes desta pasta foram gerados a partir das duas posições ilustradas de
cada exercício no [Free Exercise DB](https://github.com/yuhonas/free-exercise-db),
um conjunto de dados disponibilizado em domínio público pela Unlicense.

O script `frontend/scripts/generate-exercise-videos.ps1` registra os exercícios
de origem usados em cada arquivo e permite recriar os vídeos localmente.

As demonstrações são uma referência visual curta. Elas não substituem avaliação
profissional nem devem ser usadas se o movimento causar dor.
